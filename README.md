# Python Data Science Project: Recommendation System

## Overview

This project is a **Data Science project built entirely using Pure Python**. It starts with raw JSON data, performs data cleaning and analysis, and implements recommendation features such as **People You May Know** and **Pages You Might Like**.


## Key Features

* JSON data loading
* Data cleaning and preprocessing
* Data analysis
* People You May Know recommendation
* Pages You Might Like recommendation

## Technologies Used

* Python

## What I Learned

* Data preprocessing and cleaning techniques
* Working with JSON datasets
* Using dictionaries and sets for efficient data processing
* Implementing recommendation logic from scratch
